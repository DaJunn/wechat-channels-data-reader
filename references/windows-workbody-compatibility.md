# Windows / Workbody Compatibility

This Skill is portable as a file package, but live dashboard reading depends on the host runtime.

## Compatibility Matrix

| Environment | Live dashboard minute export | CSV/raw analysis | Requirements |
| --- | --- | --- | --- |
| macOS Codex / local agent | Supported | Supported | Node.js 18+, Python 3.10+, Kimi WebBridge, logged-in browser tab |
| Windows local agent | Supported if Kimi WebBridge is reachable | Supported | Node.js 18+, Python 3.10+, PowerShell, logged-in browser tab |
| Workbody with local command execution | Supported if it can reach `KIMI_WEBBRIDGE_URL` | Supported | Node.js 18+, Python 3.10+, local browser bridge access |
| Workbody without local browser bridge | Not supported | Supported | User uploads CSV/raw exported elsewhere |

## Windows Install

Unzip the package, then copy the `wechat-channels-data-reader` folder into the agent's skills directory. If the runtime uses the default Codex directory:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex\skills" | Out-Null
Copy-Item -Recurse -Force ".\wechat-channels-data-reader" "$env:USERPROFILE\.codex\skills\"
$env:SKILL_DIR = "$env:USERPROFILE\.codex\skills\wechat-channels-data-reader"
```

If the agent uses another skill directory, copy the folder there and set `SKILL_DIR` to that folder.

## Windows Commands

Export minute-level traffic and transaction trends:

```powershell
node "$env:SKILL_DIR\scripts\export_live_trend_minutes.mjs" --url "https://channels.weixin.qq.com/platform/statistic/dashboardV4?objetctId=<liveObjectId>&entrance_id=3"
```

Analyze an exported CSV:

```powershell
python "$env:SKILL_DIR\scripts\analyze_live_trend_minutes.py" "$env:USERPROFILE\outputs\live-trend-digitized\live_trend_store_<liveObjectId>.csv" --raw "$env:USERPROFILE\outputs\live-trend-digitized\live_trend_raw_store_<liveObjectId>.json"
```

If `python` is not available, try `py -3` or install Python 3.10 or newer and enable "Add python.exe to PATH".

## Workbody Use

Use the same Skill folder and point Workbody to `SKILL.md`.

Full live-page reading requires all of these:

- Workbody can run local Node.js commands.
- Workbody can run local Python commands.
- The machine has Kimi WebBridge running.
- `KIMI_WEBBRIDGE_URL` points to the local WebBridge endpoint, default `http://127.0.0.1:10086/command`.
- The browser already has a logged-in `channels.weixin.qq.com` dashboard tab.

If Workbody cannot access a local browser bridge, do not claim exact minute-level dashboard reading. Ask the user to provide the CSV/raw files generated by another logged-in machine, then use `analyze_live_trend_minutes.py`.

## Safety Boundaries

- Do not log in for the user.
- Do not read cookies, localStorage, sessionStorage, passwords, authorization headers, tokens, or browser profile files.
- Do not use screenshots or OCR for exact minute-level numbers.
- Do not invent WeChat endpoints or fields.
